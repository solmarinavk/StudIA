# 🎮 Fracciones Game

Una plataforma educativa gamificada para aprender a realizar operaciones matemáticas con fracciones de forma divertida e interactiva.

## ✨ Características

- **5 tipos de operaciones**: Suma, resta, multiplicación, división y simplificación de fracciones
- **Sistema de niveles**: Aumenta la dificultad a medida que avanzas
- **Sistema de puntuación**: Gana puntos por respuestas correctas
- **Racha de aciertos**: Multiplica tus puntos con rachas consecutivas
- **3 vidas por partida**: Desafío adicional para mantener la concentración
- **Interfaz gamificada**: Diseño atractivo y colorido con animaciones
- **Responsive**: Funciona perfectamente en móviles, tablets y escritorio
- **Feedback inmediato**: Aprende de tus errores con correcciones instantáneas

## 🚀 Tecnologías

- React 18
- Vite
- CSS3 con animaciones
- Matemáticas puras en JavaScript

## 💻 Instalación y desarrollo

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Construir para producción
npm run build

# Vista previa de la build
npm run preview
```

## 🌐 Despliegue en Netlify

Este proyecto está configurado para desplegarse automáticamente en Netlify:

1. Conecta tu repositorio a Netlify
2. Netlify detectará automáticamente la configuración en `netlify.toml`
3. El comando de build es: `npm run build`
4. El directorio de publicación es: `dist`

### Despliegue manual

```bash
npm run build
# Sube la carpeta 'dist' a Netlify
```

## 🎯 Cómo jugar

1. **Inicio**: Haz clic en "Comenzar a Jugar"
2. **Resuelve**: Se te presentará una operación con fracciones
3. **Responde**: Ingresa el numerador y denominador de tu respuesta
4. **Simplifica**: Recuerda siempre simplificar tu fracción al máximo
5. **Verifica**: Haz clic en "Verificar Respuesta"
6. **Avanza**: Completa 5 preguntas para subir de nivel
7. **¡Diviértete!**: Intenta conseguir la puntuación más alta

## 📊 Sistema de puntuación

- Puntos base: 10 × nivel actual
- Bonificación por racha: Multiplicador según rachas consecutivas
- Ejemplo: En nivel 3 con racha de 5 = 10 × 3 × 5 = 150 puntos

## 🎓 Operaciones incluidas

- ➕ **Suma de fracciones**: a/b + c/d
- ➖ **Resta de fracciones**: a/b - c/d
- ✖️ **Multiplicación de fracciones**: a/b × c/d
- ➗ **División de fracciones**: a/b ÷ c/d
- 🔽 **Simplificación**: Reducir a/b a su mínima expresión
