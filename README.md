# 🎮 Fracciones Game

Una plataforma educativa gamificada diseñada para **enseñar desde cero** cómo realizar operaciones matemáticas con fracciones de forma divertida e interactiva.

## ✨ Características Principales

### 📚 Modo Tutorial Completo
- **Aprende paso a paso** cada operación con explicaciones claras
- **Ejemplos visuales** con representación gráfica de fracciones
- **5 tutoriales interactivos**: Suma, resta, multiplicación, división y simplificación
- **Navegación sencilla** entre lecciones

### 🎯 Niveles de Dificultad
- **🌱 Principiante**: Números del 1 al 5 + visualización de fracciones
- **🌟 Intermedio**: Números del 1 al 10
- **🔥 Experto**: Números del 1 al 20

### 💡 Sistema de Ayuda Integrado
- **Botón de ayuda** disponible en cada pregunta
- **Solución paso a paso** que muestra cómo resolver el problema
- **Explicaciones detalladas** de cada operación matemática
- Aprende mientras juegas viendo cómo se resuelve cada ejercicio

### 🎓 Modo Práctica
- **Practica operaciones específicas** hasta dominarlas
- Enfócate en la operación que más te cuesta
- Sin límite de tiempo para aprender a tu ritmo

### 🎮 Características de Juego
- **Sistema de puntuación**: Gana puntos por respuestas correctas
- **Sistema de niveles**: Aumenta la dificultad progresivamente
- **Racha de aciertos**: Multiplica tus puntos con respuestas consecutivas correctas
- **3 vidas por partida**: Desafío adicional para mantener la concentración
- **Feedback inmediato**: Aprende de tus errores con correcciones instantáneas

### 🎨 Interfaz Educativa
- **Visualización de fracciones** (modo principiante)
- Representación gráfica de las partes
- Diseño colorido y atractivo
- Animaciones suaves
- **Responsive**: Funciona en móviles, tablets y escritorio

## 🚀 Tecnologías

- React 18
- Vite
- CSS3 con animaciones
- Matemáticas puras en JavaScript

## 🎯 Cómo Aprender a Usar la Plataforma

### Para Principiantes Totales:

1. **Comienza con el Tutorial**
   - Haz clic en "📖 Comenzar Tutorial"
   - Lee cada lección con calma
   - Observa los ejemplos visuales
   - Avanza a tu propio ritmo

2. **Practica Operaciones Individuales**
   - Desde el menú principal, haz clic en una operación específica (Ejemplo: "➕ Sumar")
   - Practica solo esa operación hasta dominarla
   - Usa el botón "💡 Ver Ayuda" cuando lo necesites

3. **Comienza en Modo Principiante**
   - Elige "🌱 Principiante" para números pequeños (1-5)
   - Verás representaciones visuales de las fracciones
   - Las fracciones se muestran como barras divididas

4. **Usa la Ayuda Siempre que la Necesites**
   - Durante el juego, haz clic en "💡 Ver Ayuda"
   - Se mostrará la solución paso a paso del ejercicio actual
   - Aprende viendo cómo se resuelve

5. **Avanza Gradualmente**
   - Una vez domines el modo principiante, prueba intermedio
   - Practica hasta poder resolver rápido
   - ¡Eventualmente llegarás a ser experta!

## 📊 Operaciones Incluidas

### ➕ Suma de Fracciones
```
1/2 + 1/4
Paso 1: Multiplica cruzado: (1 × 4) + (1 × 2) = 4 + 2 = 6
Paso 2: Denominador: 2 × 4 = 8
Resultado: 6/8 = 3/4 (simplificado)
```

### ➖ Resta de Fracciones
```
2/3 - 1/4
Paso 1: Multiplica cruzado: (2 × 4) - (1 × 3) = 8 - 3 = 5
Paso 2: Denominador: 3 × 4 = 12
Resultado: 5/12
```

### ✖️ Multiplicación de Fracciones (¡La más fácil!)
```
2/3 × 3/4
Paso 1: Multiplica numeradores: 2 × 3 = 6
Paso 2: Multiplica denominadores: 3 × 4 = 12
Resultado: 6/12 = 1/2 (simplificado)
```

### ➗ División de Fracciones
```
1/2 ÷ 1/4
Paso 1: Invierte la segunda fracción: 1/4 → 4/1
Paso 2: Ahora multiplica: 1 × 4 = 4, 2 × 1 = 2
Resultado: 4/2 = 2/1 = 2
```

### 🔽 Simplificación
```
6/8
Paso 1: Encuentra el máximo común divisor (MCD) de 6 y 8
Paso 2: El MCD es 2
Paso 3: Divide ambos: 6÷2 = 3, 8÷2 = 4
Resultado: 3/4
```

## 🎓 Consejos para Aprender Rápido

1. **No te saltes el tutorial** - Aunque tengas prisa, las explicaciones te ahorrarán tiempo después
2. **Practica una operación a la vez** - Domina la multiplicación antes de pasar a la división
3. **Usa la ayuda sin vergüenza** - Está ahí para aprender, no es trampa
4. **Empieza en principiante** - Aunque parezca fácil, te ayudará a entender visualmente
5. **Practica diariamente** - 10 minutos al día son mejor que 2 horas una vez a la semana
6. **Observa los pasos** - Cuando uses la ayuda, lee cada paso con atención
7. **Repite hasta automatizar** - La velocidad viene con la práctica constante

## 🏆 Progreso Recomendado

**Semana 1**: Tutorial completo + Práctica de Simplificación y Multiplicación
**Semana 2**: Suma y Resta en modo principiante
**Semana 3**: División en modo principiante, todas las operaciones en intermedio
**Semana 4**: Modo experto, intenta mejorar tu velocidad y precisión
